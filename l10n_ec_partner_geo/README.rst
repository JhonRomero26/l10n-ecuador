L10n EC Partner Geolocation
===========================

This module adds geolocation features to `res.partner` for Ecuadorian localizations.

Features
--------
- Interactive map picker to set partner coordinates and address
- Integration with Ecuador territorial data (province, canton, parish)
- Automatic on-change handling to update address fields from the map

Configuration
-------------
- Requires `web_map_field` and `l10n_ec_ote` to provide map widget and territorial
  data respectively.
